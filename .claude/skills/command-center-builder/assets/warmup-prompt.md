# Warm-up prompt — what the student pastes to start

This is the text behind the "Copy the warm-up prompt" button on the Week 4 page. It runs Phase 0a:
Vera finds out everything she can on her own and reports facts. She asks nothing and builds nothing.
On a live call this runs at the top, before the teaching, so the build afterwards is short.

---

Hey Vera, get me set up for the Command Center build. Load the command-center-builder skill — if you do not have it, install it from my memory vault or from the .skill file I was given, and tell me which version loaded.

Then find out everything you can on your own, and do not ask me anything yet:

1. Check my prep: can I sign into Cloudflare, is GitHub connected on Cloudflare's Create an application screen, does Zero Trust open to its own dashboard, and are both CLOUDFLARE_API_TOKEN and AIRTABLE_TOKEN in my memory vault's Actions secrets. Tell me which are done and which are missing.
2. List which of Airtable, Google Calendar, Slack, Gmail and QuickBooks I have connected right now, and which I do not. Just the list, no suggestions yet.
3. Read my Week 1 foundational skills and my vault so you know what my business actually does and how it makes money.
4. Look at my Airtable base: which tables exist, and which of them hold real data rather than being empty or seeded.
5. If QuickBooks is connected, run my P&L and check whether the last three months have income posted. Keep what you find for later; do not bring up money yet.

Then report back in about eight lines: the skill version, the four prep checks, what is connected and what is not, one line on what my business does, which tables hold real data, and the books finding if there is one. Facts only, no suggestions and no questions.

Then stop. Do not start building. I will say "build my command center" when I am ready.
