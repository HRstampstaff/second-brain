# va-welcome-email

**Version: 1.0 - 2026-09-01**

Drafts the welcome email a VA gets when they start with a client. Draft only: Mark or Kristin read
and send it, per the standing rule in CLAUDE.md.

## Trigger

"Draft the welcome email for [VA name]", "[VA name] is starting with [client]", or similar.

## What you need

- VA name and role (EA / Creative-SMM / other)
- Client name
- Start date
- Coach name
- Communication channel (Google Chat, Slack, Skype, FB Messenger, etc.)

Check the Placements and VAs tables in Airtable first (see `reference/your-base.md`) — if the
pairing is already there, use it instead of asking. Ask only for whatever is genuinely missing,
in one line.

## The email

Tone: warm but professional, plain everyday English — no special phrases (see
`business/profile.md`). Cover, in this order:

1. Congratulate the VA on the placement — name the client and the role.
2. Start date, and who they report to (the coach, for the first 4 weeks).
3. The communication channel and the check-in schedule (daily/weekly).
4. SOD/EOD reports and the Daily Task Tracker.
5. The VA coach is reachable any time at VA.Coach.GVACO@gmail.com — no need to wait for the
   weekly Team Leader call.
6. Warm sign-off.

## Output

A draft, in chat or as a Gmail draft if asked. Never send it.
